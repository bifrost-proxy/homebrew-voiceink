# Homebrew VoiceInk

Homebrew tap for the free [Bifrost Proxy VoiceInk fork](https://github.com/bifrost-proxy/VoiceInk).

Install with the fully qualified Cask name:

```shell
brew install --cask bifrost-proxy/voiceink/voiceink
```

Or use the equivalent two-step form:

```shell
brew tap bifrost-proxy/voiceink
brew install --cask voiceink
```

Upgrade to the latest GitHub Release:

```shell
brew upgrade --cask --greedy voiceink
```
